## 🌐 How to Deploy for Free (in 2 Minutes)

### Option 1: GitHub Pages (Recommended)
1. Go to your GitHub account ([github.com/TAMILSELVANM30](https://github.com/TAMILSELVANM30)).
2. Create a new repository named `TAMILSELVANM30.github.io` (or `portfolio`).
3. Push or upload the contents of this folder (`index.html`, `assets/`, `README.md`) to the repository.
4. Go to **Settings** > **Pages** > Select `main` branch and `/root` folder > Click **Save**.
5. Your portfolio will be live at:
   ```
   https://tamilselvanm30.github.io
   ```

### Option 2: Vercel / Netlify
- Drag and drop this folder onto [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop) for instant global deployment with custom SSL.
